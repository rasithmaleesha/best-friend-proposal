✨ Features
💖 Yes button that grows bigger every time you try to say No
🏃 No button that runs away from the mouse and from touch, so it can never be clicked
😭 Teddy bear and button text that change as the No button dodges
🌸 Floating hearts and sparkles animation
💌 Heartfelt wishes that fade in one by one
📱 Phone-friendly layout and automatic dark mode

🚀 How to use
Download or clone this repo
Open `index.html` in your browser. No installation needed!
```bash
git clone https://github.com/rasithmaleesha/best-friend-proposal.git
cd best-friend-proposal
```
🌐 Get a link with GitHub Pages
Go to Settings → Pages
Source: Deploy from a branch, Branch: `main`, folder `/ (root)`, then Save
Your page will be live at `https://rasithmaleesha.github.io/best-friend-proposal/`
🎥 Tip
Open the page on your phone, start a screen recording, try the No button a couple of times, click Yes, and let the wishes play (about 10 seconds). Post it as your status! 📲
✏️ Customize
Open `index.html` and change the text inside the `.wish` lines, the `<h1>` titles, or the colours at the top of the `<style>` section (`--accent`, `--bg1`, `--bg2`).
